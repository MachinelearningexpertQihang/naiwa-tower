# 奶蛙之塔 2.0

用奶蛙家族做的卡牌爬塔游戏。在线玩：https://machinelearningexpertqihang.github.io/naiwa-tower/

- 三位主角：奶蛙（厚肚皮）、功夫奶蛙（快手连击）、骑士奶蛙（铁甲）
- 五层塔，每层 9 步：泥沼回廊 → 月夜古堡 → 冰封钟楼 → 沸腾奶茶厂 → 星空之顶
- 21 位首领，每位都有专属机制和故事，首领图鉴可收集
- 337 张卡牌、66 件遗物、47 个随机事件、30 个精英
- 奶蛙池三连消除、抓敌人当伙伴、月相天气、三合一金卡、闪卡
- 多周目（最高 8 周目）、今日塔况、精英词缀、金色奶蛙、流浪商队、宝箱怪、小游戏
